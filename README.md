# design-evidence

Screenshot and measurement evidence for UI work. Not merged into dev or main.

One folder per issue or review: `evidence/<yyyy-mm-dd>-<issue-or-review>/`.

Images: 1366 or 1920 wide, JPEG q82 or optimised PNG, under about 150 KB each, at most 15 per issue.

Link to files here from the issue comment with the GitHub blob URL of this branch, for example
`https://github.com/dent-ist/MatterFlow/blob/design-evidence/evidence/2026-11-06-issue-123/after-1366.jpg`.

Older screenshot rounds (before 2026-11) are in the branch `archive/docs-screenshots-2026-11`.
