# Repository Map

[[_TOC_]]

**What this page is for.** A guided tour of every top-level folder and the important sub-folders, so you know where to look.

## Top level

| Path | What lives there |
|---|---|
| `CLAUDE.md` | Rules for AI agents and developers (module boundaries, schema rules, UI standard, commit format) |
| `README.md` | Setup, run commands, demo data, configuration table |
| `package.json` (root) | Helper scripts that start the whole stack: `setup`, `start`, `db:up`, `db:reset`, `api`, `web`, `seed:demo` |
| `docker-compose.dev.yml` | Local SQL Server 2022 and two init containers (create database, report login) |
| `global.json` | Pins the .NET SDK (10.0.100, roll forward to latest feature band) |
| `.editorconfig`, `.gitattributes` | Code style (checked in CI by `dotnet format`) and line endings |
| `backend/` | The .NET solution |
| `frontend/` | The Angular workspace |
| `contracts/` | Cross-stack contracts |
| `db/` | SQL scripts and the report access catalogue |
| `deploy/` | IIS publish scripts and configuration templates |
| `tools/` | Helper tooling: demo data seeder, performance tools, icon generator, spikes |
| `docs/` | Requirements, architecture, UX, QA, runbook |
| `app-framework/` | Design documents for a planned framework (not implemented) |
| `.github/` | GitHub Actions workflows, the shared `setup-dotnet` action, Dependabot |
| `wiki/` | This wiki |

## backend/

| Path | Contents |
|---|---|
| `backend/MatterFlow.sln` | Solution file |
| `backend/Directory.Build.props`, `Directory.Packages.props` | Shared build settings; NuGet versions live only in `Directory.Packages.props` |
| `backend/src/MatterFlow.Api/` | The host: `Program.cs`, `ModuleComposition.cs`, `Http/` (error format, filters, middleware), `Security/`, `Hosting/` (SPA hosting, migrate-only, readiness), `Seeding/` (starter configuration), `OpenApi/`, `appsettings*.json` |
| `backend/src/MatterFlow.SharedKernel/` | Types every module may use: `Results`, `Paging`, `Time`, `Visibility`, `Audit`, `Authorization`, `Entities`, `ValueObjects`, `Tasks`, `Availability`, `Text`, `Identity`, `Data` |
| `backend/src/MatterFlow.Data/` | `MatterFlowDbContext`, EF interceptors (audit, audit columns, stable plan), model conventions, `SchemaMigrations` (the script runner), cross-module relationships |
| `backend/src/Modules/MatterFlow.<Module>/` | One project per module: `Domain/`, `Application/`, `Infrastructure/`, `Api/` (some modules group files by feature instead) |
| `backend/src/Modules/MatterFlow.<Module>.Contracts/` | The module's public surface: interfaces and DTOs other modules may use |
| `backend/tests/MatterFlow.UnitTests/` | Fast tests, no Docker |
| `backend/tests/MatterFlow.ArchitectureTests/` | Module rules, authorization rules, audit scope, rowVersion rules, source hygiene |
| `backend/tests/MatterFlow.SchemaTests/` | Schema script checks against a real SQL Server (Docker) |
| `backend/tests/MatterFlow.IntegrationTests/` | HTTP-level tests with Testcontainers (Docker) |

See [Backend Modules](../Architecture/Backend-Modules.md) and [Module Guide](../Backend/Module-Guide.md).

## frontend/

| Path | Contents |
|---|---|
| `frontend/src/app/app.routes.ts` | The route tree (lazy feature routes, guards) |
| `frontend/src/app/features/` | One folder per feature (clients, matters, tasks, dashboard, admin, ...) |
| `frontend/src/app/shared/` | Shared UI: `ui`, `layout`, `filters`, `work-queue`, `tasks`, `forms`, `charts`, `guards`, `pipes`, `directives`, ... |
| `frontend/src/app/core/` | App-wide services: `auth`, `http`, `session`, `theme`, `lookups`, `availability`, `branding`, `views`, `time`, `notify`, `title`, `config`, `identity-admin` |
| `frontend/src/app/api/generated/` | The NSwag-generated API client (never edit by hand) |
| `frontend/projects/form-engine/` | A library: the dynamic form and custom-field engine shared by screens |
| `frontend/e2e/` | Playwright end-to-end tests (`tests/`, `pages/`, `fixtures/`, `support/`, `run-local.sh`) |
| `frontend/scripts/` | Lint helpers: theme colours, theme contrast, icon sizes, off-scale sizes, bundle report |
| `frontend/nswag.json` | NSwag configuration for `npm run api:generate` |

See [Folder Structure](../Frontend/Folder-Structure.md).

## contracts/

| File | Purpose |
|---|---|
| `openapi/v1.json` | The OpenAPI document, generated by the API build and committed; CI fails on drift |
| `permissions.json` | The permission catalog (70 permissions); synced into `dbo.Permission` at startup |
| `form-rules.schema.json`, `form-rules.md`, `form-rules.vectors.json`, `form-rules.messages.json` | Conditional-rule schema, semantics, shared test vectors, error message keys |
| `task-type-colours.json`, `task-type-icons.json` | Palette of ten colour keys and the icon library for task types |
| `validate-contracts.mjs` | Dependency-free checker: `node contracts/validate-contracts.mjs` |

See [API Contracts](../Architecture/API-Contracts.md).

## db/, deploy/, tools/

| Path | Contents |
|---|---|
| `db/scripts/` | 59 numbered SQL scripts (`01` to `60`, number 16 unused) and a README with the rules |
| `db/report-access.json` | Classifies every table as readable or denied for the read-only report login |
| `deploy/publish.ps1`, `publish.sh`, `configure-iis.ps1`, `web.config`, `appsettings.Production.template.json` | Production packaging and IIS setup |
| `tools/seed-demo/` | Demo data seeder (`npm run seed:demo`) |
| `tools/perf/` | Load test and timing tools with a README |
| `tools/icons/` | Task-type icon catalogue and generator |
| `tools/db/` | SQL helpers: report login provisioning, sensitive matters report |
| `tools/spike-outlook-dnd/` | Spike for dragging an email from Outlook |
