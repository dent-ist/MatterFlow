# E2E defect triage, 2026-11 (issue #1358, epic #1356)

The first full Playwright run (`docs/qa/e2e-run-2026-11-10.md`) listed seven groups of suspected real defects. Each one was reproduced on a real stack (own SQL Server container, API published from `dev` 93f6371 with Dev authentication, Chromium) at 1366x768 and 1920x1080, with traces on, running only the named spec files, one family at a time. The dashboard-v4-summary and swimlane-board families were run four times, each on a freshly created, empty database (two databases, both sizes).

Verdicts: **REAL DEFECT** (the app is wrong against the guidelines, the permission catalogue or an accessibility rule; filed as an issue under #1356), **STALE** (the app is right, the spec is old; the owning batch corrects the file, the table says how), **FLAKY** (passes on repeat, or fails only because the test is faster than the app's own timers).

## Suspicion list, item by item

1. Dialog mask intercepts pointer events (`profile-absences`, `sh5-toast-host`, `users-us3-grid`): STALE (unsaved-changes guard on Cancel; toast spec mocks the old API); `users-us3-grid` passes.
2. Focus: `sh-403-in-place`, `sh-focus-heading` STALE (Copy address comes first); `users-us1-bugs`, `mm-qa` FLAKY (timer races); `dashboard-audit` STALE (Calendar tab); `dashboard-shell` "View as pie" STALE (Bars | Pie | Table).
3. Toast where none is expected: `sh-list-load-error` forbidden list REAL (#1360), action-toast test STALE; `task-detail-t1` REAL (#1361).
4. Permission visibility: `users-tab` STALE (Skills view); `pv-asset-report-builder` Reports item STALE (Reports module); `clients-permissions` STALE (hidden columns); `users-us7-matrix` REAL (#1362).
5. Charts or period control: STALE (v4 moved the period to Trends; empty window shows text instead of a plot).
6. Counts (108 vs 104, lane 22 vs 24): not reproduced on four clean databases. The 22 vs 24 is the link height (#1364). The 108 vs 104 of `dashboard-v4-summary` did not appear (the count tests pass on a clean database); treated as parallel-spec noise on the shared database. The v4 failures that do reproduce are listed above (#1363 and two stale tests).
7. `sr6-a11y` search button: STALE (phone-only control).
