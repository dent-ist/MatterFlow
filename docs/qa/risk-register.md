# Quality Risk Register

Top 15 quality risks for MatterFlow Phase 1. Likelihood (L) and Impact (I) scored 1 to 5; Score = L x I. Test ids refer to `traceability.md` and `permission-matrix-tests.md`. Review at each phase gate; owner updates status.

| ID | Risk | L | I | Score | Mitigation | Covering tests | Owner / when |
|---|---|---|---|---|---|---|---|
| R-01 | **Dynamic forms divergence.** The .NET and TypeScript rule evaluators disagree (null handling, `neq`/`notIn`/`isEmpty` on hidden fields, string compare rules, depth, sections), so the UI shows a field as optional while the API rejects, or the server accepts invalid data. Retrofitting is costly (baseline section 20 risk) | 4 | 5 | 20 | One shared `form-rules.vectors.json` run in both stacks; every bug adds a vector; PR that changes semantics must change vectors; server authoritative; renderer prototyped first; property-based fuzz test generating random rule trees and values, comparing both evaluators in CI (TS via node harness) | FRM-01..09, FRM-03, SCN-008, K-09, UAT-S09-4, S14-4 | Forms dev (#20, #30, #31); Phase 0 to 1 |
| R-02 | **Version snapshot leakage.** Editing a Step Definition, form, or workflow alters Tasks already created (or a Task is created against a half-published or wrong version; retired versions not readable; DB triggers missing) | 3 | 5 | 15 | Immutable published rows enforced by service guard and DB triggers; Task pins `FormVersionId`, `WorkflowVersionId`; copy-on-add of step text (arch 8.1); atomic publish; filtered unique indexes; tests that compare a before/after JSON of an existing Task's rendered workflow and form | VER-01..03, FRM-07, FRM-08, IMM-02, SCN-014, UAT-S15-2, S16-5 | Workflow and forms devs (#29, #38, #39); Phase 2 |

## Triggers for escalation

- Any vector mismatch between .NET and TS found in production-like testing: stop feature work on forms until resolved.
- Nightly integration red 2 days in a row: PM pauses new tickets in the affected module.
- FND-01, 02, 05 unresolved by end of Phase 2: Task epic (#8) start is blocked (they change the lifecycle and completion contract).
- Windows-auth rehearsal fails or is not scheduled by the end of Phase 1.
