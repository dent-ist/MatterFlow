# Inline column filters: UX re-review, 2026-10-20

Independent re-review of epic #75 ("Inline column filters on every grid") before its close. Reviewer: a UX and QA agent that did not build the batches (#76 foundation, #77 record lists, #78 work lists, #79 administration). Tree: `origin/dev` at `bcdb669` (the Task Types, Workflows and Steps lists were re-checked on `ed4d04b` after the Task Types wave rebuilt them: open from 640 px, one Clear filters, axe 0, sheet and cards at 375), built and published fresh (`deploy/publish.sh` through `frontend/e2e/run-local.sh`), SQL Server 2022 in Docker, Dev authentication, `npm run seed:demo` (1,300 tasks, 61 users, 5 clients, 12 matters, 4 projects, 60 assets) plus the starter configuration. Chromium only. The fixes are in the commits that carry this file; "before" is `bcdb669`.

Source of truth: `docs/ux/column-filters-review.md` (inventory of 36 surfaces, pattern standard in section 4), `docs/ux/column-filters/README.md`, `docs/ux/ux-spec.md` (5.2), `docs/requirements/decisions-addendum.md` (T to W, and X written with this review).

**Verdict: no High and no Medium finding is open.** Four Medium findings were found (RR-01 to RR-04) and fixed with regression tests; five Low and four Nit findings are recorded (three Low and two Nit fixed). Details and the bar below.

## 1. Method

1. Every surface of the inventory was opened at **1366x768, 1920x1080, 768x1024 and 375x812** (screenshots, DOM facts: filter bar, row open or closed, controls with their names and placeholders, chips, Clear filters, horizontal page scroll, console errors).
2. Behaviour scripts on every filtered grid: first text filter typed (URL, count, chips with the row closed, Clear), Esc, reload (URL state, row opens), `/`, the Filters sheet at 375 and 768 (focus, Esc, live apply, "Show N results", targets), print emulation (`Filters: ...` line, bar and row hidden), multi-select popover (Esc returns focus, outside click, scroll), the date range and its presets, From after To, a filter on a hidden column, Other filters, Back after a select change, live region text.
3. **axe-core 4.10.2** (wcag2a, wcag2aa, wcag21aa, wcag22aa) on every surface at 1366 (default, row open, filtered) and at 375 (default, sheet open, filtered): 0 violations on all of them before and after the fixes (the e2e suite repeats this for every converted screen).
4. Performance on 1,301 tasks (Task Queue; the machine had a load average of 20 to 30 from other agents, so the numbers are upper bounds): first page 1.2 s, typing a 15-character title filter sent **one** request (debounce), the list settled in 2.7 s, 20 scroll frames in 0.32 s.
5. Pattern standard and docs checked against the code (section 6).

Screenshots are in `re-review/` (names below).

## 4. Verified good

- **One definition drives everything.** Row, sheet, chips, count, URL and API arguments come from one `FilterDef[]`; names are "Filter by <column>" on every control; the Filters button announces `aria-pressed`, `aria-expanded`, `aria-controls` and the count `(n)` (`tq-1366.png`, `matters-1366.png`).
- **Row open or closed rules** match the decisions: open on the three work lists and (from 640 px) the four record lists, closed elsewhere, remembered per person, opened by an address that carries filters (reload tested on 21 grids).
- **Defaults are not counted**: Status Active or Open shows in its cell, `Filters` carries no count and no chip; "All" is a counted filter.
- **Chips**: shown when the row is closed (`tq-chips-row-closed-1366.png`), "(hidden column)" with "Show column" for a filter on a hidden column (`tq-hidden-column-chip-1366.png`); Other filters lists the hidden-column and column-less filters (`tq-other-filters-1366.png`).
- **URL state**: typing replaces the history entry, selects push (Back restores the select), any change resets the page, a reload restores values and opens the row.
- **Keyboard**: `/` opens the row (or sheet) and focuses the first text filter on all 21 grids; Esc clears a filled box, closes a popover (focus returns to its button) or the sheet; outside click and grid scroll close a popover.
- **Sheet**: `role=dialog`, `aria-modal`, focus inside, Esc returns focus to Filters, live apply with "Show N results", targets 40 px or more, sort in the sheet on the work lists and records (`tq-sheet-375.png`, `audit-sheet-375.png`); no page-level horizontal scroll on any surface at any of the four sizes.
- **Dates**: presets set absolute dates in the viewer's zone (`tq-due-presets-1366.png`); From after To is reported and not applied (`audit-date-range-error-1366.png`); the chip names a preset while the range equals it.
- **Print**: every filtered grid prints "Filters: Title or Ref zz, Status Open" with the bar, row and button hidden (21 grids).
- **Live region**: one polite message per filter change ("6 clients"), none per keystroke.
- **Empty and states**: headers and the filter row stay in every state; "No <noun> match these filters" with one Clear filters (RR-02) and the hidden-records sentence (RR-04) (`tq-empty-one-clear-1366.png`).
- **Performance**: debounce sends one request per typed word; 1,301 tasks page in about a second on a loaded machine.
- **axe**: 0 violations on every surface and state listed in section 1.
