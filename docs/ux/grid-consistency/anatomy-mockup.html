List page anatomy: proposal

One layout for every list. The zones are always in this order; a zone that does not apply is left out, never moved. Tokens come from docs/ux/tokens.css; buttons follow theme guide section 9 (32 px, primary filled, others outlined); the dropdown menu shows the check at the right. Not a build: static HTML to talk about.
